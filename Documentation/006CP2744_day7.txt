package com.example;

public class a4_Parameterized {
    public static boolean isPalindrome(String s){
        String str = "";

        for(int i = 0; i<s.length(); i++){
            str += s.charAt(i);
        }
        if(str.equals(s)){
            return true;
        }
        return false;
    }
}





Task 05:
What is Junit Life cycle hook (set up tear down) ?

JUnit Life Cycle Hooks are special methods that are executed before and after test methods. They help prepare the test environment (setup) and clean it up (teardown).

- Setup: Runs before a test to initialize objects or resources.
- Teardown: Runs after a test to release resources or reset the environment.

Task 10:
Now what do you think are the different types of Junit 5 tests we have … list them down

Ans:
Unit Test (@Test) – Tests a single method or functionality.
Parameterized Test (@ParameterizedTest) – Runs the same test with different input values.
Exception Test (assertThrows()) – Verifies that the expected exception is thrown.
Timeout (Performance) Test (assertTimeout()) – Checks whether code executes within a specified time.
Repeated Test (@RepeatedTest) – Executes the same test multiple times.
Disabled Test (@Disabled) – Skips a test temporarily.
Nested Test (@Nested) – Groups related test cases.
Dynamic Test (@TestFactory) – Creates test cases dynamically at runtime.



Task 11:
Write about JVM architecture using a diagram.
Ans:
JVM (Java Virtual Machine) is a part of the Java Runtime Environment (JRE) that executes Java bytecode. It provides platform independence by converting bytecode into machine code.

Class Loader
- Loads .class files into memory.

Method Area
- Stores class information, static variables, and method data.

Heap Memory
- Stores objects and instance variables.
- Managed by the Garbage Collector.
Java Stack
- Stores local variables, method calls, and function execution.
PC (Program Counter) Register
- Stores the address of the currently executing instruction.
Native Method Stack
- Executes native methods written in languages like C/C++.
Execution Engine
- Executes bytecode.
Garbage Collector
- Automatically removes unused objects from heap memory to free memory.



Task 12:
Why are enums useful?

Ans:
Enum (Enumeration) is a special data type in Java used to define a fixed set of constants. It improves code readability, type safety, and maintainability.

Represents a fixed set of constants
- Example: Days of the week, Months, Directions, Colors.
Improves code readability
- Uses meaningful names instead of numbers or strings.
Provides type safety
- Prevents assigning invalid values.
Easy to maintain
- If a new constant is needed, it can be added in one place.

public class BankingStringFunctions {
    public static void main(String[] args) {

        String bankName = "State Bank of India";
        String customerName = "Narayana R";
        String accountNumber = "SBI123456";
        String message = "Welcome to SBI";

        // length()
        System.out.println("Length: " + bankName.length());

        // toUpperCase()
        System.out.println("Upper Case: " + bankName.toUpperCase());

        // toLowerCase()
        System.out.println("Lower Case: " + bankName.toLowerCase());

        // charAt()
        System.out.println("First Character: " + customerName.charAt(0));

        // substring()
        System.out.println("Branch Code: " + accountNumber.substring(0, 3));

        // equals()
        System.out.println("Equals: " + bankName.equals("State Bank of India"));

        // equalsIgnoreCase()
        System.out.println("Equals Ignore Case: " + bankName.equalsIgnoreCase("state bank of india"));

        // contains()
        System.out.println("Contains SBI: " + message.contains("SBI"));

        // startsWith()
        System.out.println("Starts With State: " + bankName.startsWith("State"));

        // endsWith()
        System.out.println("Ends With India: " + bankName.endsWith("India"));

        // replace()
        System.out.println("Replace SBI: " + message.replace("SBI", "ICICI"));

        // indexOf()
        System.out.println("Index of Bank: " + bankName.indexOf("Bank"));

        // concat()
        System.out.println("Concat: " + bankName.concat(" - Bangalore Branch"));

        // trim()
        String user = "  Narayana R  ";
        System.out.println("Trim: '" + user.trim() + "'");

        // isEmpty()
        String str = "";
        System.out.println("Is Empty: " + str.isEmpty());

        // compareTo()
        System.out.println("CompareTo: " + "Savings".compareTo("Current"));

        // split()
        String transaction = "Deposit,5000,Success";
        String[] data = transaction.split(",");
        System.out.println("Transaction Type: " + data[0]);
        System.out.println("Amount: " + data[1]);
        System.out.println("Status: " + data[2]);
    }
