Task 11:
How many types of DI do we have?Explain

- Constructor Injection: In constructor injection, dependencies are provided through the constructor at the time the object is created.
- Setter Injection: In Setter Injection, Spring injects dependency into an object using setter methods after the object is created.
- Field Injection (DI): In Field Injection, Spring injects dependency directly into class fields using @Autowired.

We have spring annotations:
Like

Can you give a liner about these


1.@Bean
Used in a configuration class to manually define and create a bean that will be managed by Spring.

2.@Controller
Marks a class as a Spring MVC controller that handles web requests and returns views.

3.@Value
Injects values from properties files or environment variables into fields.

4.@ComponentScan
Tells Spring to scan specified packages for components, services, repositories, and controllers.

5.@Configuration
Indicates that a class contains bean definitions and Spring configuration.

6.@Service
Marks a class as a service layer component that contains business logic.

7.@Repository
Marks a class as a Data Access Object (DAO) that interacts with the database.
8.@Qualifier
Used with @Autowired to specify which bean should be injected when multiple beans of the same type exist.

9.@Required
Marks a setter method as mandatory, ensuring the dependency must be injected (deprecated in Spring 5).

10.@Component
Marks a class as a Spring-managed component, making it a candidate for auto-detection during component scanning.

11.@Autowired
Automatically injects dependencies into a class by type.

12.@Scope
Defines the scope of a bean such as singleton, prototype, request, or session.

 In this above code ..
What is the internal working of above code .. 
Give thhe step by step explanation 


1.@SpringBootApplication Annotation
Combines @Configuration, @EnableAutoConfiguration, and @ComponentScan to enable auto-configuration and component scanning.

2.SpringApplication.run() Execution
Creates SpringApplication instance, loads configuration files, and initializes Spring IoC container.

3.Auto-Configuration
Reads META-INF/spring.factories, loads auto-configuration classes, and configures beans based on classpath dependencies.

4.Component Scanning
Scans current package for @Component, @Service, @Repository, @Controller and registers them as beans.
