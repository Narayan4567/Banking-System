Task 6:
Wap to create an array list
Use lambda exp in foreach 
Check if the num is even or odd

import java.util.ArrayList;

public class ArrayListLambdaDemo {
    public static void main(String[] args) {

        // Create an ArrayList
        ArrayList<Integer> numbers = new ArrayList<>();

        // Add elements
        numbers.add(10);
        numbers.add(15);
        numbers.add(20);
        numbers.add(25);
        numbers.add(30);

        // Use lambda expression with forEach
        numbers.forEach(num -> {
            if (num % 2 == 0) {
                System.out.println(num + " is Even");
            } else {
                System.out.println(num + " is Odd");
            }
        });
    }
}

Task 08:
List down the annotations of Junit 5

Uses annotations such as:
@Test – Marks a test method.
@BeforeEach – Runs before every test.
@AfterEach – Runs after every test.
@BeforeAll – Runs once before all tests.
@AfterAll – Runs once after all tests.




Task 09:

Difference between Junit 5 and Junit 4

JUnit 4
- Uses @Before and @After
- Uses @BeforeClass and @AfterClass
- Supports basic testing features
- Does not support Java 8 features well

JUnit 5
- Uses @BeforeEach and @AfterEach
- Uses @BeforeAll and @AfterAll
- Supports advanced features like parameterized tests, nested tests, repeated tests, and dynamic tests.
- Fully supports Java 8 and later features, including lambda expressions

Task 15:
What are default and static methods in interfaces?

A default method is a method in an interface that has a body (implementation). Classes implementing the interface automatically inherit it, unless they choose to override it.

A static method belongs to the interface itself, not to the implementing class.It is called using the interface name, not through an object.

What is the double colon :: operator ?

What is method Reference in java 8?

A Method Reference is a feature introduced in Java 8 that allows you to refer to an existing method or constructor using the :: (double colon) operator instead of writing a lambda expression.
