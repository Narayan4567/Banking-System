Task 1:
What is spring data JPA?


Spring Data JPA is a Spring framework module that simplifies database operations in Java applications by reducing boilerplate code and automatically generating database queries using JPA and repository interfaces.

- It allows developers to interact with databases using Java objects instead database queries using JPA and repository interfaces. It allows developers to interact with databases using Java objects instead of writing large amounts of SQL manually.





Task 2:
What are the key features of Spring data JPA?

- Reduces boilerplate database code
- Provides built-in CRUD operations
- Automatically generates SQL queries
- Supports custom query methods
- Uses repository interfaces for database access
- Integrates with JPA and Hibernate
- Supports pagination and sorting
- Supports transaction management
- Provides support for relationships between entities
- Converts Java objects into database tables using ORM
- Easy integration with Spring Boot
- Supports native SQL and JP queries





Task 3:
What are core components of Spring data JPA?

- Entity
- Java class mapped to a database table using @Entity
- Repository
- Interface used for database operations
- JpaRepository
- Predefined Spring Data JPA interface providing CRUD methods
- JPA (Java Persistence API)
- Specification for ORM and database interaction
- Hibernate
- Default JPA implementation that converts Java operations into SQL

CustomerController.java
package com.example.demo;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.*;
import java.util.List;
@RestController
@RequestMapping("/customers")
public class CustomerController {

    @Autowired
    private CustomerRepository repository;
    @PostMapping
    public Customer createCustomer(@RequestBody Customer customer) {
        return repository.save(customer);
    }
    @GetMapping
    public List<Customer> getAllCustomers() {
        return repository.findAll();
    }
    @GetMapping("/{id}")
    public Customer getCustomer(@PathVariable Integer id) {
        return repository.findById(id).orElse(null);
    }
}

What is Application.proteries file is about?

It stores application settings in key-value format, so developers can configure the application without changing Java code.




Task 7:
Why use application properties… uses?

- Configure server settings
- Connect databases
- Configure Spring Security
- Manage environment-specific settings
- Store custom application values




Task 8:
What is application.yml?

application.yml is a configuration file in Spring Boot, similar to application.properties.
It is used to store application settings like Server port, Database configuration, Security settings, Logging configuration.




Task 9:
Why use/prefer to use  application.yml instead of application.properties?

application.yml is often preferred over application.properties because it is more readable and better organized, especially for large Spring Boot applications.
- Easier to read
- Better structure with indentation
- Supports hierarchical/nested configuration naturally

What do you know about Spring MVC framework?

Spring MVC is a Java framework used to build web applications and REST APIs using the Model-View-Controller design pattern.
It is part of the Spring Framework and helps separate application logic, user interface, and request handling in a clean and organized way.

MVC stands for:
- Model → Handles data and business logic
- View → Displays data to the user
- Controller → Handles HTTP requests and responses
